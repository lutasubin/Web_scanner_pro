# Web Scanner Pro

Base Android Flutter/Kotlin cho phiên WhatsApp Web liên kết, Status Saver, lịch sử thông báo cục bộ, chat nhanh và quản lý tệp đã lưu.

2. [Đặc tả](docs/02_PRODUCT_SPEC.md)

4. [Kế hoạch](docs/04_IMPLEMENTATION_PLAN.md)
5. [Kết quả và giới hạn](docs/05_DELIVERY.md)

```bash
flutter pub get
flutter analyze
flutter test
flutter build apk --debug
```

APK debug được tạo tại `build/app/outputs/flutter-apk/app-debug.apk`.
